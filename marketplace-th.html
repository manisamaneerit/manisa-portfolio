    AKK Shop – แพลตฟอร์มมาร์เก็ตเพลสหลายร้านค้า

    ออกแบบ UX/UI และพัฒนาระบบ Full Stack · อยู่ระหว่างพัฒนา

    ภาพรวมโครงการ

    AKK Shop เป็นแพลตฟอร์มอีคอมเมิร์ซแบบหลายร้านค้า (Multi-Vendor Marketplace) ที่เชื่อมต่อผู้ซื้อกับผู้ขายอิสระภายในระบบเดียว ครอบคลุมตั้งแต่การค้นหาสินค้า เลือกสินค้าใส่ตะกร้า ชำระเงิน ตรวจสอบคำสั่งซื้อ และติดตามการจัดส่ง พร้อมหน้าจัดการเฉพาะสำหรับร้านค้าและผู้ดูแลระบบ

    ระบบออกแบบโดยให้ความสำคัญกับประสบการณ์ผู้ใช้ โครงสร้างข้อมูลที่เป็นระบบ และขั้นตอนการทำงานจริงของธุรกิจ โดยแยกส่วนลูกค้า ผู้ขาย และผู้ดูแลระบบ รองรับการบริหารร้านค้า สินค้า สต็อก คำสั่งซื้อ การชำระเงิน การจัดส่ง และการตั้งค่าเว็บไซต์

    ฟังก์ชันของระบบ

    ระบบลูกค้าและการสั่งซื้อ

    • สมัครสมาชิก เข้าสู่ระบบ ออกจากระบบ แก้ไขข้อมูลส่วนตัว และจัดการที่อยู่จัดส่ง
    • หน้าแรกมาร์เก็ตเพลส แค็ตตาล็อกสินค้า หมวดหมู่ ผลการค้นหา หน้าร้านค้า และรายละเอียดสินค้า
    • จัดการตะกร้าสินค้าและตรวจสอบข้อมูลก่อนเข้าสู่ขั้นตอนสั่งซื้อ
    • สรุปรายการสั่งซื้อ ยืนยันคำสั่งซื้อ และคำนวณค่าจัดส่งแบบเหมาจ่ายต่อคำสั่งซื้อหรือต่อชิ้น
    • ประวัติคำสั่งซื้อ รายละเอียดคำสั่งซื้อ และติดตามการจัดส่ง
    • เชื่อมต่อระบบชำระเงิน Viva และรับผลการชำระเงินกลับเข้าสู่ระบบแล้ว โดยอยู่ระหว่างทดสอบกรณีผิดปกติ

    ระบบผู้ขายและการจัดการร้านค้า

    • ลงทะเบียนผู้ขาย สมัครเปิดร้าน และติดตามสถานะคำขอ
    • แดชบอร์ดร้านค้า แก้ไขข้อมูลร้าน ตั้งค่าการจัดส่ง และตั้งค่าข้อมูลการรับชำระเงิน
    • จัดการหมวดหมู่สินค้า เพิ่มและแก้ไขสินค้า รวมถึงจัดการภาพสินค้า
    • จัดการสินค้าคงคลังและสต็อก
    • จัดการคำสั่งซื้อของร้าน ประมวลผลคำสั่งซื้อ การยกเลิก และบันทึกข้อมูลจัดส่ง/เลขติดตาม

    ระบบผู้ดูแลและจัดการแพลตฟอร์ม

    • ระบบเข้าสู่ระบบสำหรับผู้ดูแลและแดชบอร์ดภาพรวม
    • จัดการลูกค้าและผู้ขาย รวมถึงตรวจสอบคำขอเปิดร้านค้า
    • จัดการสินค้า หมวดหมู่ คำสั่งซื้อ การชำระเงิน และการจัดส่งจากส่วนกลาง
    • ตั้งค่าข้อมูลรับชำระเงินของร้านค้าและข้อมูลเว็บไซต์
    • การแจ้งเตือนภายในระบบเกี่ยวกับคำสั่งซื้อ การชำระเงิน และการจัดส่ง พร้อมหน้านโยบายการใช้งาน ความเป็นส่วนตัว และการคืนสินค้า/คืนเงิน

    บทบาทของฉัน

    ออกแบบและพัฒนาโครงการ ตั้งแต่การวิเคราะห์ความต้องการ วางโครงสร้างระบบและฐานข้อมูล ออกแบบ UX/UI เขียนโค้ด Frontend และ Backend เชื่อมต่อระบบ ไปจนถึงการทดสอบและปรับปรุงอย่างต่อเนื่อง

    • ริเริ่ม วางแผน ออกแบบ และพัฒนา AKK Shop ทั้งระบบด้วยตัวเองเพียงคนเดียว ตั้งแต่โครงสร้างเริ่มต้นจนถึงการลงมือพัฒนา
    • วิเคราะห์ความต้องการทางธุรกิจ วางฟังก์ชันทั้งหมด ออกแบบเส้นทางการใช้งานของลูกค้า ผู้ขาย และผู้ดูแล
    • ออกแบบ UX/UI ใหม่ทั้งหมด รวมถึงเลย์เอาต์ Responsive การนำทาง หน้าค้นหาสินค้า การสั่งซื้อ และแดชบอร์ด
    • ออกแบบฐานข้อมูลเชิงสัมพันธ์ กำหนดตารางและความสัมพันธ์ พร้อมเขียนโค้ด Frontend และ Backend เองทั้งหมด
    • พัฒนาระบบบัญชีลูกค้า การสมัครร้านค้า สินค้า สต็อก ตะกร้า เช็กเอาต์ คำสั่งซื้อ การจัดส่ง และเครื่องมือผู้ดูแล
    • เชื่อมต่อการชำระเงิน Viva และผลตอบกลับ พร้อมทดสอบการจัดการข้อผิดพลาด ความสอดคล้องของข้อมูล และความพร้อมใช้งานจริง

    สถานะการพัฒนา

    ฟังก์ชันหลักสำหรับลูกค้า ร้านค้า และผู้ดูแลระบบได้รับการพัฒนาแล้ว ระบบชำระเงิน Viva เชื่อมต่อและรับผลการชำระเงินกลับเข้าสู่แอปพลิเคชันได้แล้ว ขณะนี้อยู่ระหว่างตรวจสอบกรณีพิเศษและทดสอบขั้นสุดท้ายก่อนนำระบบขึ้นใช้งานจริง

    งานที่กำลังดำเนินการ

    • ระบบลืมรหัสผ่านและตั้งรหัสผ่านใหม่
    • ตรวจสอบผลตอบกลับการชำระเงินและการทำงานร่วมกับข้อมูลคำสั่งซื้อ/ชำระเงินของระบบกลาง
    • ทดสอบการยกเลิกและกรณีตัดบัตรไม่สำเร็จ รวมถึงการอัปเดตสถานะคำสั่งซื้อและการชำระเงินอย่างถูกต้อง
    • เพิ่มความครอบคลุมของการจัดการข้อผิดพลาด สิทธิ์การเข้าถึง บันทึกเหตุการณ์ และสำรอง/กู้คืนฐานข้อมูล
    • ทดสอบระบบอย่างเป็นทางการ แก้ไขข้อบกพร่อง และนำขึ้นใช้งานจริง

    เทคโนโลยีที่ใช้

    • Frontend: HTML, CSS, JavaScript, jQuery, Bootstrap
    • Backend: PHP, AJAX, JSON
    • ฐานข้อมูล: MySQL / MySQLi
