เว็บแอปพลิเคชันสมัครสมาชิกและซื้อคอร์ส เชื่อมต่อ Fitness POS

พัฒนาเมื่อ - 2024 December

เว็บแอปพลิเคชันที่เหมาะสำหรับแท็บเล็ต ใช้ลงทะเบียนสมาชิกฟิตเนสและซื้อคอร์สฝึกออกกำลังกาย เชื่อมต่อกับ Fitness POS เดิม เพื่อให้พนักงานเพิ่มข้อมูลสมาชิก จัดการการซื้อ และบันทึกธุรกรรมได้รวดเร็ว ข้อมูลซิงก์กับ POS แบบเรียลไทม์ เพื่อให้การคิดเงินและติดตามสมาชิกถูกต้อง

ฟังก์ชันของระบบ

  • ลงทะเบียนสมาชิก สร้างโปรไฟล์ ถ่ายภาพ และลงลายเซ็นดิจิทัล
  • ซื้อคอร์สและแพ็กเกจผ่านหน้าจอที่เหมาะสำหรับแท็บเล็ต
  • ซิงก์ข้อมูลกับ Fitness POS ที่มีอยู่แบบเรียลไทม์
  • บันทึกธุรกรรมและติดตามประวัติการซื้ออย่างละเอียด
  • ค้นหาสมาชิกและเปิดดูโปรไฟล์ได้รวดเร็ว
  • ดีไซน์ Responsive ที่เหมาะกับ iPad และแท็บเล็ต

เทคโนโลยีที่ใช้

  • Frontend: HTML, CSS, JavaScript, jQuery, Bootstrap
  • Backend: PHP, AJAX, JSON
  • ฐานข้อมูล: MySQL / MySQLi

บทบาทและความรับผิดชอบ

  • ออกแบบกระบวนการทำงานและโครงสร้างฐานข้อมูลทั้งระบบ
  • พัฒนาทั้ง Frontend และ Backend
  • เชื่อมต่อข้อมูลแบบเรียลไทม์กับ POS ของฟิตเนส
  • พัฒนาส่วนลงทะเบียนสมาชิก ซื้อคอร์ส/แพ็กเกจ และประมวลผลธุรกรรม
  • ปรับ UX/UI ให้เหมาะสำหรับการใช้งานบนแท็บเล็ต
