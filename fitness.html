Membership Registration & Course Purchase Web App Connected to Fitness POS

development - 2024 December

A tablet-friendly web application for registering fitness members and purchasing training courses. The system connects directly to the existing fitness POS system, allowing staff to quickly create member profiles, manage purchases, and record transactions. All data is synced with the POS system in real time for accurate billing and member tracking.

System Features

  • Member registration with profile creation, including photo capture and digital signature.
  • Course and package purchasing through a tablet-optimized interface.
  • Real-time data synchronization with the existing fitness POS system.
  • Transaction recording with detailed purchase history tracking.
  • Member search and quick profile lookup.
  • Responsive design optimized for iPad and tablet devices.

Technologies Used

  • Frontend: HTML, CSS, JavaScript, jQuery, Bootstrap
  • Backend: PHP, AJAX, JSON
  • Database: MySQL / MySQLi

My Role

  • Designed the entire system workflow and database structure.
  • Developed the entire front-end and back-end.
  • Integrated real-time data synchronization with the fitness center's existing POS system.
  • Developed modules for member registration, course/package purchases, and transaction processing.
  • Optimized the UI specifically for tablet use.
